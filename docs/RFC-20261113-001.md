## 0. 术语与约定

| 术语 | 定义 |
|---|---|
| **EAL** | 平均接受长度 = 1 + Σ_{k=1..5} pos_k（vLLM per-position 口径） |
| **pos_k / d_k** | 投机解码第 k 深度接受率 |
| **h0 契约（recursive）** | 每深度 block 输入 = h0 + 真值 emb(t[i+k])，深度间独立（slot 轴注意力） |
| **链式契约（serving_c / 契约 C）** | d1=prefill 同位配对填全 prompt KV；d2..dK=(norm(out_{k-1}), emb) 解码链；vllm 0.27 源码逐条核对 |
| **fp32 master** | 训练域以 fp32 保存的可训练参数（交付时 cast 到 vendor dtype） |
| **ACC margin 项** | 逐深度 `mean(relu(m − (logit[target] − max_other)))` |
| **int8 地板** | W8A8 合并时 |delta| < 半格点的更新被取整吞没 |
| **成熟度探针** | 同 checkpoint 双臂（int8 ∥ FLOAT 表达）EAL 差值符号 |
| **交付形态** | bypass 线性层 serving 取 int8 合并还是 bf16 FLOAT |
| **精度链** | 参数从训练域到 serving 域经历的 dtype 变换序列 |
| **命名空间** | V1/V2/V3/V5 独立的输出目录/评测脚本/端口/结果文件前缀 |

编号体系：`REQ-<域>-<n>`（域：ARCH/DATA/LOSS/FWD/OPT/RT/DIST/SRV/CLI/EVAL）、
`ADR-n`、`G-A<n>`、`T-<类>-<n>`、`M<n>`、`OPEN-<n>`、`E-<n>`。

## 2. 原理：SFT+MTP 训练在做什么，为什么这样设计

### 2.1 GLM MTP 原理与 serving 几何（P-0 根源）

GLM MTP = **一层 block 跑 K 次**（链式）：d1 = prefill（(h0[p], emb(t[p])) 同位
配对，填 draft KV）；d2..dK 输入 = eh_proj(enorm(emb), hnorm(**norm(out_{k-1})**))，
attend 全 prompt KV + 自身链 KV，位置随深度 +1。**这是 GLM 原生原理，也是
vllm deepseek_mtp 的 serving 实现（vllm 0.27 源码逐条核对）——两者一致，因此
训练几何 MUST 链式（REQ-LOSS-2 / ADR-11）。h0 平行契约（recursive）与该原理
存在双重失配（隐藏来源 + 注意力几何），失配沿深度复合（d5 ~5×）——P-3 的
首要候选根因。**

### 2.2 关键性质（全部规格的推导根源）

| 编号 | 性质 | 推论 |
|---|---|---|
| **P1** | EAL 对深度加法：+1pt = +0.01 EAL；d4/d5 headroom 最大（12% vs vendor 22.91%） | 目标覆盖全 5 深度；深度加权指向 d4/d5 |
| **P2** | CE 与 greedy top-1 解耦 | 需要 top-1 对齐项（REQ-LOSS-3）；单 CE 训练存在接受率天花板 |
| **P3** | int8 取整=低通滤波：sub-ULP 被吞，过格点才表达 | 表达是成熟度函数；探针符号为唯一判据（REQ-SRV-1） |
| **P4** | teacher-forced 训练 = 对 vendor 自洽态的扰动（CP15 -0.655） | 早期负值合法；演进曲线 > 单点 |
| **P5** | base-LoRA 同训 = draft 追移动 target（增量 cos 0.34-0.61） | freeze 使方向收敛（REQ-OPT-2） |
| **P6** | K 深度共享全部 block 参数 | 深度相关改动 MUST 单变量 A/B；K 的选择影响全部深度（ADR-9） |
| **P7** | 深度权重可解析重加权 | 深位低成本杠杆（REQ-LOSS-4） |
| **P8** | **原理一致性**：训练几何 MUST = GLM 原生链式原理 = vllm serving 实现 | 链式契约为目标态（ADR-11）；h0 契约为过渡兼容基线 |
| **P9** | **训推一致性**：训练可见的输入分布/注意力几何/算子语义 MUST 与 serving 一致，否则失配沿深度复合 | 算子符合度矩阵（REQ-FWD-5）；teacher-forced 镜像是工程折衷（token 真值、hidden 链式） |
| **P10** | 参数参与 = 影响力 × 成本 两维决策 | 参数全景矩阵（REQ-ARCH-2）；LoRA=对高影响低容量子空间的低成本高保真路径（ADR-10） |
| **P11** | **精度链**：训练域精度决定更新质量（fp32 master 累积），交付域精度决定表达（cast/int8 网格） | 两域精度分别规格化（REQ-RT-5/6）；"训练提升被交付吞掉"是 P3 而非训练精度不足 |
| **P12** | 评测集 consumed48 = 训练消费样本 → 度量的是**自洽重建**，不是泛化 | 泛化 MUST 另立 heldout 对照（REQ-EVAL-3 / OPEN-7） |

### 2.3 工作示例（margin 项手工演算）

logits=[1.2, 0.3, -0.1]，target=0，m=0.5：t=1.2，max_other=0.3 → relu(0.5-0.9)=0。
t=0.35：relu(0.5-0.05)=0.45。聚合 = supervised 行均值（与 chunked CE sum/count 同构）。

## 8. 规范性规格 — ARCH 域

### 8.1 MTP K 的决策（REQ-ARCH-1 / ADR-9）

**REQ-ARCH-1**：训练深度 K MUST = 5，与 serving k=5 一致。K 的变更 MUST 走
OPEN-1 流程（独立探针臂 + 双侧判读）。

**决策理由（训 K=5，不训 K=7）**：
1. **serving 消费集**：vLLM `num_speculative_tokens=5`，EAL 只加 d1-d5；
   d6/d7 无消费通道（P1）
2. **梯度稀释**：K 深度共享全 block 参数（P6）；CE 阶梯 [1.11,2.71,4.15,5.00,5.44]
   单调变难，d6/d7 梯度噪声更大 → 摊薄 d1-d5 有效梯度
3. **输入失配随深度增大**：teacher-forced 真值 emb(t[i+k]) 在 serving 链中是
   draft 自采样（低质）；深度越深，训练教的"依赖高质量未来输入"在 serving
   越不可得
4. **成本**：序列化深度 backward 逐深度回传，K=7 步时 +40%（432→~570s/it 实测
   外推，**需重测**）
5. **反方论点（记录在案）**：辅助深度对共享 trunk 有正则化可能—— countered by
   2/3；若要验证走 OPEN-1（K=7 探针臂，d1-d5 对照）
6. **深位目标的正确杠杆**：K=5 内深度加权（P7/REQ-LOSS-4）与几何对齐（ADR-11），
   而非增加不服务的深度

端 W8 重合并的格式风险；同时 master cast fp32 保证更新累积精度（P11）。

### 8.3 扩参与规则（REQ-ARCH-3）

扩任何冻结组件进训练 MUST 满足：(a) 可微或提供 STE；(b) 交付格式可表达；
(c) 显存增量 < 5G；(d) 单变量 A/B 通过 G-A1。不满足 → OPEN。

## 9. 规范性规格 — DATA 域

**REQ-DATA-1**：数据集 = `cmb_eagle_30k`（30k 样本，conversations jsonl，
dataset_info 注册）；评测锚点 = `consumed48_prompts.jsonl`（训练消费样本，
ADR-12）。数据变更 MUST 走新 RFC。

**REQ-DATA-2**：template=glm5_next_text；cutoff_len=2048（ADR-13）；字符长度
分布 p50=6.3K/p90=22.4K/p99=53.7K chars（**实测来源=本会话抽样**）→ 长样本
截断为已知折衷；32K 实验留 OPEN-8（V2 显存边界实证 2048 是安全点）。

**REQ-DATA-3**（缓存并发）：16-rank 并发 tokenization 在 LF `num_proc` 路径存在
fork+pyarrow 竞态（实测 SIGSEGV）→ MUST 先 1-rank 预热缓存再全量启动，或
`preprocessing_num_workers` 路径验证后放行。

## 10. 规范性规格 — LOSS 域

**REQ-LOSS-1**：`GLM53_MTP_CONTRACT_JOINT` 缺省/`recursive` → 与 V1/V2/V3 逐位
一致。测 T-UNIT-1。

**REQ-LOSS-2（v2，几何契约）**：**训练几何的目标态 = 链式（serving_c，与 GLM
原生原理及 vllm serving 双一致，P8/P9）**。过渡期（M4 对照窗口）MUST 保留
recursive 路由作对照基线；M4 出数后默认值切换 MUST 经用户确认。
测 T-UNIT-2。

**REQ-LOSS-3**（ACC margin）：w>0 时两契约逐深度并入 `w·aw_k·margin_k`；缺省
w=0 逐位兼容。测 T-UNIT-3。

**REQ-LOSS-4**（深度权重解析）：归一化/退化/不泄漏 env。测 T-UNIT-4。

**REQ-LOSS-5**（聚合语义）：`mean(rows)×cnt == Σ supervised-row`（含 -100）。
测 T-UNIT-5。

**REQ-LOSS-6**：契约 C MUST NOT 套 0.0 序列化边（链梯度经 cache 流动）；
`mtp_loss_weight` 外层乘语义一致。测 T-UNIT-6。

## 11. 规范性规格 — FWD 域

**REQ-FWD-1**：head 前向 row-chunk（512 缺省），MUST NOT 全序列 logits 常驻。
**REQ-FWD-2**：契约 C 几何规格（d1 prefill 全 prompt KV；d2..dK n_q=S-k+1、
位置 p+k-1、attend=prompt KV(≤p+k-1)+链 KV+self；mask 语义见实现锚点）。
**REQ-FWD-3**：0.0-edge 仅 recursive。**REQ-FWD-4**：HBM 上界（需重测）。

**REQ-FWD-5（算子符合度矩阵）**：训练算子与 serving 的一致性 MUST 按下表
管理；"近似"项 MUST 在评测解读时声明：

| 算子/语义 | serving | 训练 | 符合度 | 状态 |
|---|---|---|---|---|
| MTP 链几何 | 链式 norm 回喂+prompt KV | 契约 C 逐条对齐 | ✅ 源码核对（vllm 0.27） | V5 生效 |
| 注意力 kernel | vllm ascend 后端 | torch attn（enforce-eager 等价语义） | ✅ 数学等价 | — |
| DSA indexer topk | **复用 step-0 indices**（skip_topk） | 每步重算 + prev_topk 全选旁路 | ⚠️ 近似（OPEN-6） | 已声明 |
| 量化线性 | ascend 量化 kernel（int8 动态） | QuantShardLinear 在线反量化 | ✅ ModelSlim 位级对齐（串行包验证） | — |
| MoE | 路由+专家 int8 | GLM53_MTP_MOE_LOOP 路径 | ⚠️ 未逐项核验 | 标注 |
| rotary/位置 | 随深度 +1 | 契约 C 同构 | ✅ | — |
| lm_head | vendor F32（serving bf16 计算流） | fp32 master+chunked | ✅ 数值口径一致 | — |

## 12. 规范性规格 — OPT/RT 域

**REQ-OPT-1**：AdamW 分组 = mtp fp32 master 组（lr 1e-5）+ lora 组（lr 1e-4）+
（V3-F）冻结组；状态 fp32 on CPU（GLM53_ADAM_CPU=1，ZeRO-1 分片）。**REQ-OPT-2**：
freeze 钩子 one-shot，日志 `[v3] base-LoRA frozen`。

**REQ-RT-4（LF 补丁面与 GAP 清单）**：LF 使用面 = 上游 `4759a8de` → 本地
`83788da4` 三 opt-in 钩子（branch-1 training_step / _save / create_optimizer
fp32 分组）。已知 GAP（每项 MUST 有状态）：

| GAP | 现象/约束 | 状态 |
|---|---|---|
| branch-1 盲调 multi_microbatch_loss | loss 构造完全在模型侧；LF 不感知契约路由 | by-design（V5-S1 在模型侧路由） |
| LF-native 双机 loss=203 | 未根因（V4 已 DROP，§6）；自研路径 5.59 健康 | OPEN-5 |
| gradient checkpointing 不支持 | 自定义模型未接 HF checkpointing 接口（日志 WARN） | 已知限制（内存靠峰值治理） |
| gradient_as_bucket_view 缺失 | transformers 5.14.1 无此参数 | 用 DDP_BUCKET_VIEW 自研开关 |
| tokenization num_proc 16-rank 竞态 | fork+pyarrow SIGSEGV 实测 | REQ-DATA-3（预热缓存） |
| 上游 pin 链 | accelerate≥1.15/peft≥0.21/trl≥1.17 会 pin transformers≤5.8 | 版本锁（§21） |
| average_tokens_across_devices | 显示口径修正项 | 配置固定 false |
| 多机 sampler | DistributedSampler seed=42 按 ranks 分片；跨 rank 无重叠 | 2 机 32 卡时消费序列变化（已文档化） |
**REQ-RT-1**：env 契约表（v1 表 + `GLM53_MTP_CONTRACT_JOINT`）。
**REQ-RT-2**：生效标记三件套。**REQ-RT-3**：版本锁（post4/5.14.1）。

**REQ-RT-5（训练精度链）**：可训练参数 MUST 以 fp32 master 存储并全程 fp32
累积（AdamW 状态 fp32 CPU）；激活 bf16（autocast）；梯度经 DDP bucket fp32。
禁止 bf16 参数原位累积（P11——"训练不进去"的根因防线）。

**REQ-RT-6（交付精度链）**：fp32 master → vendor dtype cast（FLOAT 件）/ →
dequant+delta→int8 重格点（W8 件）/ → bf16 FLOAT（FLOAT_SET 件）；每级变换
MUST 有 reldiff 留档（build 验证块）。serving 生成 MTP 层精度 = resident bf16
（FLOAT 件）或 int8 网格（合并件）——精度越大越好由 FLOAT_SET 承载，成熟度
探针定夺。

**REQ-RT-8（可观测性）**：LOSS_DECOMP（ce/margin 阶梯）、BWD-watch（峰值）、
fill [mem] 阶梯、生效标记——训练运行 MUST 至少保留前两类日志。
