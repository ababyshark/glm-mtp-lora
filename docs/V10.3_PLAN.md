# V10.3 设计方案 — 联训配方止血（窄域覆写减速 + 蒸馏纯净 + 冻结脆弱面）

> 2026-11-23 立项。编号裁决：**V10.3**（用户裁决，不用 V12——避免与 W8A8 量化线 V11 撞名）。
> 北极星不变：vLLM serving 原生前缀接受长度 K̄（382 用例三组，/metrics 计数器）。

## 〇、证据链（为什么开 V10.3）

| 臂（同步数 100） | K̄(G1) | K̄(G2) | 结论 |
|---|---|---|---|
| base（纯 vendor） | — | — | **3.521** 全池锚点 |
| bisect（LoRA-only，MTP 回 vendor） | — | — | 3.20+（联训代价基准）|
| V10.1（KL top-128×2.33 + agree 0.5 + margin 0.3 + draft-CE 1.0→降权线） | 2.342 | 2.426 | 配方修复失败 |
| V10.2（专家五变量：LR 4×/draft-CE 0.25/top-128/va 锚/cosine） | **1.962** | **2.007** | 更差 |

两条根因（V10_TRAIN §11.6 已定案，V10.2 数据再度坐实）：
1. **窄域分布覆写**：30k 数学/QA 全参微调 MTP，洗掉万亿预训练的通用先验；
   KL/agree/margin 全是**训练分布内**的约束，serving 面对自生成宽分布时失效。
2. **有效步长过大**：MTP LR 2e-5 + loss 总权重 3.38 → 单步覆写量 ~22× 于 V10.3；
   V10.2 的 MTP 位移（o_proj/q_b delta ~1.0）比 V10.1 大一个量级。

训过样本无收益（G2−G1 从 V10.1 的 +0.084 缩到 +0.045）与拆分实验
"训过更差"（V10.2_CONSULT §二）同机理：漂移均匀打击，无记忆效应。

## 一、设计裁决（用户拍板）

1. **不冻结主模型，保持联训**（LoRA + MTP 同循环；moving-target 风险由
   极小步长 + dec.detach 缓解）——推翻两阶段解耦方案。
2. **单变量纪律**：与 V10.2 唯一差异 = 配方（loss 权重/KL 实现/LR/clip/
   冻结面）。同 yaml、同底座（/root/serve_v101_cp100）、同 30k 数据、同 seed。
3. **回放安全**：V10.3 代码改动默认值全部保持 V10.2 行为（TOPK_KL 默认
   128、冻结旋钮默认 OFF）——重跑 launch_v102_train_34.sh 字节不变；
   V10.3 启动器显式钉新值。
4. **冻结 eh_proj 不做**（默认可训）：它是 draft 的入口投影、真实学习者；
   旋钮 GLM53_V10_FREEZE_EH_PROJ 留作消融。

## 二、配方（相对 V10.2 的全部 delta）

| 项 | V10.2 | V10.3 | env |
|---|---|---|---|
| KL 实现 | top-128 截断重归一化 | **全词表 chunked_vocab_kl**（弃截断的分布外概率泄漏） | GLM53_V10_TOPK_KL=0 |
| KL 权重 | 2.33 | **0.8** | GLM53_MTP_DISTILL_WEIGHT |
| agree-CE(va) | 0.5 | **0.2** | GLM53_V10_AGREE_W |
| margin | 0.3 | **0** | GLM53_V10_MARGIN_W |
| draft-CE | 0.25 | **0** | GLM53_V10_DRAFT_W |
| main CE | 1.0 | **1.0**（LoRA 车道不动） | — |
| MTP LR | 2e-5 | **3e-6** | GLM53_V10_MTP_LR |
| warmup / clip | 20 步 / 5.0 | **5 步 / 1.0** | GLM53_V10_WARMUP / CLIP |
| cosine → min | 1 → 1e-6 | **1 → 5e-7** | GLM53_V10_COSINE / MIN_LR |
| MTP 冻结面 | 全参（599 键/rank） | **router + 全部 RMSNorm 冻结**（~589 键/rank） | GLM53_V10_FREEZE_MTP_ROUTER/NORMS |

冻结面明细（enorm/hnorm/final_layernorm/input_ln/pre_mlp_ln/q_a_ln/
kv_a_ln/indexer.k_norm.{weight,bias}/mlp.router —— 窄域梯度不再冲刷
路由分布与 norm 链；训练态实测 V10.2 中这些键 router 动了 0.19、norms
动了 0.009-0.018、indexer 恒零）。

Loss 语义：`L = main_CE + 0.8·KL_full(p_main.detach ‖ p_draft) + 0.2·CE(p_draft, argmax(p_main))`
—— 目标 100% 纯粹指向"拟合主模型分布 + 命中主模型 argmax"，语料锚定项清零。

## 四、实验路线（严格单变量）

- **Arm A（止血验证）**：100 步，30k 数据不变 → cp100 → 导出 → 382 bench。
  判据：K̄ ≥ V10.1 的 2.34（不再倒退）= 配方方向成立；目标域 3.15-3.28
  （回到 bisect 附近）。
  前置参照：Step-0 EVAL-FIXED argmax-agree ≈ **0.75**（训练分布固定批口径；
  勿与 serving D1 0.843 混读）。
- **Arm B（数据变量）**：代码/超参一字不改，仅换数据 =
  50% 业务 on-policy 自生成（冻结主模型贪心解码，含 <think> 链，
  消灭 exposure bias）+ 50% 通用回放自生成（先验压舱石）；加
  IGNORE_INDEX response-only mask（§7.5 挂账项落地）。300-500 步，
  每 100 步 serving K̄。
- **多深度**：D1-only 先行跑通；K̄ 超 3.20 后再议 D2/D3 深度权重
  （V5.4a 配方迁移）。

## 五、判据

- K̄(V10.3) > 3.20（bisect）= 联训约束下 MTP 对齐训练有正贡献
- K̄ ≥ 3.521（base）= 追平 base，配方修复成立
- 若 Arm A 仍低于 2.34：冻结面/蒸馏纯净假设证伪 → 回查 root cause
  （候选：agree-CE 0.2 权重不足 / 冻结面未覆盖真正的病灶 / LR 仍过大）
