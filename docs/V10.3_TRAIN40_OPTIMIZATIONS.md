# V10.3 Train-40 数据归因 → On-policy 轮工程优化点

来源:V10.3 .40 从零臂(BF16 base,冻结 router+norms,全词表 KL)前 100 步训练数据精确复原
(step n = `randperm(30000, seed=42)[n-1]`,S 与日志 25/25 步逐一对拍)。完整报告见源仓
`lf_glm53_qlora_mtp/reports/V103_TRAIN40_RUN_REPORT.md`。

## 1. 数据事实(前 100 步)

| 维度 | 数值 |
|---|---|
| 类型分布 | code 34 / math 28 / zh 19 / en 14 / med-zh 5 |
| 长度分布 | 76/100 顶满 1024 截断;10 步 600-1023;**14 步 <600(最短 305)**;均值 928 |
| 难度极差 | assistant 字符数 580~45124(截断前) |
| 归因 | dacc 低谷步 16/18/21/24 全为 zh 长文;高峰步 17/29 全为 math/code;step 8(en,43830 字符硬截 1024)loss 4.32 + dacc 0.434 双料最差;step 25(code 17350 字符)loss 3.03 |

单步 dacc 的位置级二项 SE 仅 ±1.6pt,实测 ±10-15pt → 方差由**样本间难度差**主导
(EVAL-FIXED 固定 token 线平滑单调,对照成立)。

## 2. 优化点 1:Sequence Packing + 梯度累积

**问题**:B=1 下 24/100 步未填满 1024(最短 305),~10% 有效算力空转;短样本整段
梯度直接打进单步更新,五类域梯度方差逐步裸露。

**方案**(下一轮 On-policy / V12):
- Sequence Packing:多条短样本拼满 1024/2048 窗口,配**文档级 block-diagonal
  causal mask**(样本间不可见,避免跨文档 attention 泄漏);
- 或最低成本先上 `gradient_accumulation_steps = 8`:8 条混合域样本平均后再更新,
  单次更新的梯度五类域自动平滑,顺带缓解 clip=1.0 下的有效步长抖动。

## 3. 优化点 2:训练截断长度对齐 serving(cutoff 2048)

**问题**:step 8 类超长文(4.3 万字符)硬截 1024,serving 时 `<think>` 链常态跑到
2048-4096 token——训练分布(≤1024)与推理分布(≤4096)在长链后半段错位,MTP
接受率在长链后段无训练覆盖。

**方案**:下一轮 cutoff_len 放宽到 **2048**。显存账:本 run alloc 47.3G / resv 53.1G
(910B 64G 卡,~10G 余量);cutoff 翻倍主要抬 activation 段(已 full-recompute),
需在下一轮启动前跑一次 OOM 探针(先 2048×B=1 单步冒烟)。

## 4. 边界

- 本轮(Arm A)配方/数据冻结不动,只等 CP100 → 382 bench 终审(K̄ ≥ 2.34 及格,
  3.15-3.28 目标带);优化点仅进下一轮。
- packing 若上,需同步核查 mcore 对 pack 的 position_ids/loss-mask 语义与
  MTP 深度链(no-roll patch)在 packed 边界的行为。
